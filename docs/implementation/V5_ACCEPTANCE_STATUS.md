## 当前可核对的结果

- `provider-ui-sequence/result.json`：20/20 真实 Qwen 小型生成输入，20 条合法 NO_SERVICE；P95 3,209 ms。原文/标准化文件及哈希保存；没有真实图像/眼镜显示。
- `automatic-capture-result.json`：2 次基线 + 1 次手动请求，含重试 6 张真实照片，蓝牙和 P2P 均使用；该轮 0 张质量通过。
- `device-soak-interruption.json` / `device-soak-exit-info.txt`：30 分钟测试在约 201 秒后被系统管家 force-stop，**未通过**；不能与之后的新进程拼接。
- `installed-identity-runtime-device.txt`：实际安装构建信息跨停止/导出保留的独立测试；研究应用 PID 未变化。
- `peer-restart-result.json`：实际重启眼镜 OPSTATE，手机同一会话换 epoch、重新同步时钟并再次收到真实照片；指令确认 44 ms、拍照 836 ms、传输 282 ms。只有 1 个主请求，不能作为 P95 gate。
- `display-receipt-gate.json`：20 轮、40 条真实回执，决策到可见 median 86 ms / P95 172 ms；20 次沉默截图 0 像素变化。输入和模型是明确的 fixture，未使用实际相机。
- `display-sequence-validation.json`：80 请求/原文/决策、40 回执、725 条审计记录，全部通过。测试驱动配置哈希修复后完整重跑；保留最终有效导出，清理初轮临时产物。
- `tools/report_runtime_metrics.py`：先校验完整导出，再报告计数/分位数。缺记录、样本不足和未证明连续就绪均显式标记。

两个设备已部署当前业务实现。长测已取消并停止测试进程，研究记录保留。独立 Android 短回归为 14 项通过，Python 为 33 项通过；本次只完成开发整理、环境迁移与短回归。Track A、参与者 pilot、长期独立运行和明亮实景完整联合评估没有执行，不以组件证据替代。
