# Privacy and provenance statement

- This bundle was produced as a clean-room OPSTATE implementation kit.
- No source file from the private `RealTopia-main.zip` was readable or copied.
- The bundle does not contain private project code, package inventory, secret
  values, credentials, endpoints, media assets or build artifacts.
- `tools/sanitize_private_repo.py` is provided for a later controlled audit. It
  defaults to dry-run, reports hashes/actions rather than file contents, and
  redacts secret values.
- Android integration code is original reference code and must be adapted to the
  actual SDK after hardware and repository access are available.
