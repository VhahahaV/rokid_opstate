# OPSTATE 手机研究控制台

交付目标是原生 Android 应用，视觉方案直接实现为 Compose 组件；HTML 原型不替代可运行应用。

已有上下文：V5 的 Connection / Session / Scenario / Live / Trial / Logs / Export / Settings，BVL_AN00 真机，以及 January V10 R6 公共数据。采用高保真、单一明确方向，不增加与研究任务无关的营销内容。

- 视觉方向：精密、安静的现场研究仪表。浅灰白背景、深墨绿主区、绿色成功、琥珀色等待、红色故障。
- 导航：总览、会话、数据、设置；连接与试次详情使用二级页面，减少一次展示的操作数量。
- 信息层级：先回答“是否可以开始、现在发生了什么”，再展示观察、锚点、投递和回执。
- 字体：原生系统 CJK 字体，28/22/18/16/14/12sp 层级；数值使用等宽字体，正文保持足够行高。
- 交互：触控目标至少 48dp，主动作唯一突出，错误就近显示，危险操作独立确认。
- 真实性：没有会话就显示空态；没有 SDK 连接就显示待连接。数据包统计来自校验后的 catalog，不伪造实验指标。
- 图片：只用当前真实观察或明确标注的数据集素材。评测 Gold 与教师回执不进入正式操作界面。
- 验证：Android 构建、实际导航、不同状态截图、真机触控/字体/滚动检查。

已落地的回放/审阅细节：深墨绿会话摘要卡、原生进度条、服务/沉默/待查筛选、独立试次图像卡、证据引用、可折叠原文预览及 Android 文件保存界面。正文和原文分层，避免把大段技术 JSON 作为默认界面。标签页独立滚动，二级详情返回保留列表位置；异步加载显示进度，避免重复触发重型查询。
